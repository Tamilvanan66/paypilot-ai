# 🚀 PayPilot AI
### AI-Powered Smart Commerce & Payment Assistant

**Build Smarter. Sell Better. Grow Faster.**

PayPilot AI is an AI-powered commerce assistant designed to help small businesses simplify online selling, improve customer experiences, manage products and orders, and explore intelligent business insights.

## ✨ Key Features

- 🤖 AI-powered customer assistant
- 🛍️ Product catalogue management
- 🎯 Smart product recommendations
- 📦 Order management dashboard
- 💳 PayPal Sandbox payment workflow
- 📊 Business analytics dashboard
- 📈 Revenue and order tracking
- 🌙 Modern dark fintech interface

## 🛠️ Technology Stack

**Frontend**
- React
- Vite
- CSS
- Lucide React

**Backend**
- Node.js
- Express.js
- REST APIs

**Database**
- MongoDB
- Mongoose

**Integrations**
- PayPal REST API Sandbox
- AI API integration

## 📂 Project Structure

- `client/` - React frontend
- `server/` - Express backend
- `README.md` - Project documentation

## ⚙️ Getting Started

1. Clone the repository.
2. Install frontend and backend dependencies.
3. Configure environment variables using the `.env.example` files.
4. Start MongoDB.
5. Start the backend and frontend servers.

See the setup instructions below for details.

## 🔐 Security

- Keep API keys and credentials on the backend.
- Never commit `.env` files.
- Use PayPal Sandbox for development.
- Verify payment status and amounts on the server.
